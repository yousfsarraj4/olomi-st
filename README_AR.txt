حزمة تحويل اللعبة إلى APK  (علومي حبيب قلبي ابو حسين)
=========================================================
المحتويات: www/index.html  هو اللعبة نفسها (ملف واحد).  ويضاف إليه إعداد Capacitor.

الطريقة 1 — بدون كمبيوتر ولا Android Studio (عبر GitHub، مجاناً):
 1) أنشئ حساباً على github.com ومستودعاً جديداً (Repository).
 2) ارفع كل محتويات هذا المجلد (بما فيها المجلد المخفي .github) إلى المستودع.
 3) افتح تبويب Actions ← اختر «Build APK» ← Run workflow.
 4) بعد دقائق افتح التشغيل المكتمل ونزّل الملف alomi-game-apk (فيه app-debug.apk).
 5) انقله إلى هاتفك وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

الطريقة 2 — على كمبيوتر فيه Node.js 18+ و Android Studio:
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android      (ثم Build ▸ Build APK)

ملاحظات:
 - هذا APK تجريبي (debug) صالح للتثبيت المباشر. للنشر على Google Play تحتاج توقيع (release) وحساب مطوّر.
 - لم أستطع بناء الـ APK هنا (لا يوجد Android SDK ولا اتصال بالشبكة)، فالملفات جاهزة لكن لم يُختبر البناء.
 - حجم اللعبة نحو 13 ميغابايت لأن الصور والأصوات داخلها.
 - لتغيير الاسم أو المعرّف عدّل capacitor.config.json (appId / appName).
